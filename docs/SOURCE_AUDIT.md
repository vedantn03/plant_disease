# Advisory source audit status

The previous source-audit claims are superseded by [`ADVISORY_AUDIT.md`](ADVISORY_AUDIT.md). Earlier passages and publisher attributions were not independently traceable and must not be used as agronomic advice. In particular, `plantdisease.net` is not a Cornell domain, and its Cornell attribution has been removed.

Only source text whose cited page and passage were checked may appear in the active knowledge base. Unchecked entries are placeholders that direct the user to consult a local agronomist. The legacy advisory generators are retained for history but must not be run until every source has been re-checked.
